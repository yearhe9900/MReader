# 阅读M（MReader）—— 干净、轻快的多平台电子书阅读器

阅读M 是一款为「专心读一本书」而做的电子书阅读器。它没有商城、没有社交，只把**打开书、读下去、记住进度、随手整理**这几件事做顺。软件在 Android、Windows、iOS、macOS、Linux 上界面与功能一致，你在哪台设备读，体验都一样。

## 支持的电子书格式

- **EPUB / TXT**：主力格式，打开极快，目录、正文、封面自动识别。
- **MOBI / AZW3**：Kindle 常见格式，自动分章、显示书名作者与封面（少数老式压缩格式会提示暂不支持）。
- **PDF**：以整页方式阅读；带密码的 PDF 出于安全考虑不支持打开。
- **CBZ / CBR**：漫画、画册类，按图片页阅读。

> 导入时按文件**实际内容**判断格式，不必纠结扩展名；少数损坏、加密或不完整的文件会给出明确的中文提示，不会白屏或崩溃。

## 主要功能

**阅读体验**
- 纵向连续滚动，一镜到底读完整本书，没有翻页打断。
- 默认沉浸全屏，点一下正文**正中**即可唤出 / 收起顶部导航与底部工具栏，边角误触少。
- 字号、行距、页边距、字体、背景主题、亮度都能实时调整，改完立刻生效、阅读位置不跳。
- 翻页方式可选：滑动 / 覆盖 / 无动画。
- 打开书有「纸张从右侧滑入」的转场，封面先到、正文随后铺开，不白屏等待。

**目录与定位**
- 目录：按书中层级列出章节，点一下直接跳过去。
- 书签：随手标记，随时回到记号处。
- 全书搜索 / 阅读内查找：输入关键词，定位到具体章节与位置。
- 底部章节滑条：拖动即可在章节间跳转，并实时显示当前进度。

**整理与导入**
- 书架以封面网格展示，支持搜索（原地展开，边输入边出结果），可按导入时间 / 最近阅读 / 书名 / 作者 / 手动排序。
- 「添加图书」可导入本地文件；手机端可选任意文件，桌面端保留格式筛选。
- 长按书卡：继续阅读、查看书籍详情、移出书架。
- 宽屏（平板 / 桌面）自动切换为左侧导航栏，布局更宽松。

**听书（TTS）**
- 双引擎：系统朗读 + 在线朗读，可随时切换。
- 后台朗读：锁屏、通知栏、耳机线控都能控制；来电自动暂停、挂断恢复。
- 朗读设置：语速音色、定时停止（可设「播完本章」），朗读进度与阅读进度联动。

**AI 助手**（需自行配置一个 OpenAI 兼容接口，密钥加密存储、不落明文）
- 章节摘要 / 全书摘要 / 前情回顾：读累了，让 AI 帮你捋一遍。
- 跟书问答：基于本书内容回答，答案带引用、可点回原文。
- 人物关系与设定梳理。
- 划词翻译 / 释义 / 生词本：选中一段即可翻译或加入生词本。

**阅读统计**
- 总时长、活跃天数、读过的书；按周 / 月的柱状图与全天热力图；按书排行与连续阅读天数。

## 支持的平台

Android、Windows、iOS、macOS、Linux——五端同源，界面与功能一致。Android 已提供发布安装包，其它平台可直接构建运行（个别平台能力可能略有差异，按设备诚实呈现）。

## 三步上手

1. **添加图书**：在书架点右下角「更多 → 添加图书」，选一本本地电子书；重复的书会自动去重。
2. **开始阅读**：点书卡即开书，自动回到上次读到的位置。正文中央轻点唤出菜单，底部六格（目录 / 书签 / 外观 / 操作 / 查找 / 日间夜间）与章节滑条都在这里。
3. **个性化**：点「外观」调字号、行距、背景与翻页方式；点「操作」可进入 AI 摘要、朗读设置等。

## 常见问题

- **为什么有的书没有目录 / 图片不显示？** 少数电子书本身没有目录信息，或把图片、表格做成了特殊格式。阅读M 会尽力还原书中内容，但无法凭空补全书里没有的部分。
- **听书没声音？** 检查一下设备是否装了语音引擎（系统朗读依赖系统语音包）；在线朗读需在「朗读设置」里正确填写接口。Linux 上若未安装语音引擎会提示「本机未安装语音引擎」。
- **AI 功能点开是空的？** AI 需要在「我的 → AI 设置」里配置一个 OpenAI 兼容接口（密钥加密保存），配置并测试连接后即可使用。
- **进度没同步？** 本版本专注单机阅读，已移除多设备同步；阅读进度、书签与设置都保存在本机。
- **漫画 / 扫描版 PDF 怎么读？** 这类书以整页图片呈现，适合缩放查看，不具备按段落排版与朗读。
- **我的数据安全吗？** 所有阅读数据都保存在本机；AI 密钥通过系统安全存储加密保存，不进日志。

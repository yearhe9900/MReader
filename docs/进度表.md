> - **负责人**：`AI` = agent 执行（编码 / 测试 / 文档 / 提交）；`负责人` = 本人（构建实机、拍板、全量测试令、验收）。
> - **时间**：已完成行 = **实际**完成日期；未完成行 = **基线推算**（按 schedule §0.1「3 人天/周」串行推算，仅供对照——实际推进远快于基线）。

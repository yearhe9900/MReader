# 阅读呈现引擎与分页方案（三参考实现对比 + MReader 落地路线）

> **性质**：选型调研，**只出方案不实施**。六问已由负责人拍板（2026-09-30，记录与验收条目见 §6）。
> **触发**：负责人 2026-09-30——「MReader 需要考虑多种翻页模式，如左右滑动、左右覆盖，就需要采用分页方案」，并给出四条硬保证：① 打开图书性能高、不肉眼卡顿；② 全书进度、章节进度准确；③ 翻页或滚动动画流畅不丢帧；④ 目录跳转章节迅速、不肉眼卡顿。
> **参考实现**（均只读调研）：`D:\Projects\567Reader\567Reader`（Kotlin/Compose，Legado 二开，原生自绘分页）、`D:\Projects\anx-reader`（Flutter + WebView 内嵌 foliate-js，CSS 多栏分页）、`D:\Projects\567Reader\legado_flutter-2026`（Legado 的 Flutter 移植参考实现，原生分页，**同构参考**）。
> **事实截止**：2026-09-30（行号以三仓当日工作区为准）。

## 0. 结论先行

| 项 | 结论 |
|---|---|
| **总路线** | **原生分页引擎**（Flutter 自研测量式分页）——**不走** anx 的 WebView 路线（理由 §1.2）；架构骨架抄 **567Reader** 的「排版/绘制分离 + 页流水线」，同构实现参考 **legado_flutter-2026**，进度真值抄三家收敛的**字符偏移**模型 |
| **四保证 → 机制** | ① 开书快 = **结构缓存 + 目标页增量分页 + 延迟一切非目标章工作**；② 进度准 = **字符偏移真值 + 字数加权全书进度**（本项目已有 `totalCharCount()` 原料）；③ 动画流畅 = **动画期间只回放已排版页图层，零排版零 rebuild**；④ 跳转快 = **三章窗口预分页 + 占位页 + 一次性落位**（分页天然消解滚动模型的「校正收敛」复杂度） |
| **关键约束（Flutter 事实）** | `TextPainter`/`dart:ui` 文本排版**只能在 root isolate**——567Reader 的「排版跑 IO 线程」在 Flutter 无对应物；分页必须**主 isolate 增量排版（每帧时间预算）**，这是与 Kotlin 版最大的结构差异，legado_flutter 的 `compute` 分页是死代码且存疑（§1.3） |
| **对现有定案的冲击** | M1-T04「全部章节进一个 ListView 连续滚动」被本方案**取代**（负责人指令即推翻依据）；`chapterPos` 几何比例语义须改字符偏移（§2.2）；**未被推翻**：语义坐标 `(chapterHref, …)` 真值框架、isolate 解析层（PERF-01/02）、`ChapterCache` LRU、`typeset.dart` 行内模型、玻璃态红线——全部保留复用 |

## 1. 三参考实现：路线与四保证机制

### 1.1 567Reader（Kotlin/Legado）——机制最完整的蓝本

**路线**：epublib `readEpubLazy`（zip 条目级懒物化，`LazyResource` 只存 href+size，`ResourcesLoader.java:50-87`）→ Jsoup 清洗 → **`TextChapterLayout` 排版流水线**（`Dispatchers.IO` + `Channel<TextPage>` 逐页产出，`TextChapterLayout.kt:129,132-191`）→ `Canvas onDraw` 绘制（只画不排，`TextPage.draw` `TextPage.kt:301-312`）→ `PageDelegate` 六种翻页模式（滑动/覆盖/仿真/滚动/无动画/封面，`delegate/` 目录）。

| 保证 | 机制（文件:行号） |
|---|---|
| ① 开书快 | 章节列表来自 Room、**非首次开书零解析**（`ReadBook.kt:103`、`ReadBookViewModel.kt:132`，文件 mtime 未变不重解析 `BookExtensions.kt:303-305`）；正文命中 `book_cache` **磁盘缓存**、EPUB 首读即回写（`BookHelp.kt:400-421`）；排版在 IO 线程、**排到目标页（`containPos(durChapterPos)`）才上屏**，此前显示占位页（`ReadBook.kt:728-735`）；±1 章并发预排版（`ReadBook.kt:534-543`） |
| ② 进度准 | `durChapterPos` = **字符索引**（页首行首字符在处理后正文中的位置，`Book.kt:103-105`；排版时逐行累计 `calcTextLinePosition` `TextChapterLayout.kt:1029-1047`）；反查 `getPageIndexByCharIndex` **二分**（`TextChapter.kt:226-255`）。**已知弱点**：全书百分比**章节等权**（`TextPage.kt:240-254`），长短章不均时观感进度不匀——此点**不抄** |
| ③ 动画不丢帧 | **排版与绘制彻底分离**；`CanvasRecorder` **整页预渲染**（API≥29 RenderNode / 24-28 Bitmap，行级+页级两级 recorder，`renderThread` 单线程预录 prev/cur/next/nextPlus **4 页**，`ContentTextView.kt:183-206,764-766`）；横向翻页动画期间**只回放整页截图**（`HorizontalPageDelegate.kt:16-35` 的 `setBitmap` + Cover 的 translate+clip 回放 `CoverPageDelegate.kt:22-53`）——动画期零排版零逐字绘制 |
| ④ 跳转快 | 点击瞬间占位页上屏（不空等）→ 排版覆盖目标位置后**一次性落位**（无「先滚后跳」，`ReadBook.kt:452-468,728-746`）；±1 预排版让相邻跳秒开 |

**可直译件**：占位页先行 + 目标位一次性落位；±1 章预排版窗口；整页预渲染/截图回放（仿真翻页用 3 张可复用 Bitmap + Matrix 变形 `SimulationPageDelegate.kt:103-158`）。
**不抄**：章节等权全书百分比；`durChapterPos` 是「处理后字符串」的偏移（替换规则变化会漂移，我们用 `ExtractedSection.paragraphs` 的稳定口径）。

### 1.2 anx-reader（Flutter + WebView/foliate-js）——进度模型最好，路线不可取

**路线**：**正文渲染完全不在 Flutter 侧**——foliate-js 在 `flutter_inappwebview` 里跑，shelf 本地 HTTP 服务器喂 EPUB，「分页」是浏览器 CSS 多栏（`paginator.js:283-318` `columnize()`），Flutter 只做壳 UI。无 isolate、无 epubx、无 TextPainter。

| 保证 | 机制（文件:行号） |
|---|---|
| ① 开书快 | zip **只读中央目录**建 entry Map、按章解压（`book.js:595-606`）；OPF/nav 小 XML 立即解析、**非目标章 DOM 永不解析**（`epub.js:948-968`）；章节资源 blob **引用计数缓存 + 切章级联释放**（`epub.js:615-678`）；元数据/封面**导入期**用 headless WebView 预取入库，打开零成本（`book.dart:558-634`） |
| ② 进度准 | **CFI = DOM 文本节点 + 字符偏移**（`epubcfi.js:260-310`），与排版无关、重排不漂移；全书百分比 = **字节（uncompressedSize）加权**（`progress.js:58-98`）；几何位置（当前页）实时由可见边界**二分反推字符偏移**（`bisectNode` `paginator.js:38-47`），**只在 relocate 时算一次**；重排后按锚点重对齐（`paginator.js:634`）。**已知弱点**：`goToFraction` 反向是页比例近似而非精确字符 |
| ③ 动画不丢帧 | 整章 CSS 多栏**一次排版**、章内翻页纯滚动（页=滚动偏移）；rAF 补间直接设 `scrollLeft`（`paginator.js:6-16`）；触摸滚动期**跳过 relocate 昂贵 DOM 遍历**、停手 200ms 防抖（`paginator.js:1140-1156`）；`contain: layout paint size` + `content-visibility: auto`（`paginator.js:205-207`） |
| ④ 跳转快 | 同章跳转只 `scrollToAnchor` 瞬时完成（`paginator.js:1254`）；跨章在 iframe **display:none→block 的同一同步任务链**内排版好再显示，首帧即在正确页（`paginator.js:226-257`）；程序化滚动抑制中间态 relocate（`paginator.js:1049,1163-1164`）。**已知缺口**：跨章 loading 期只有灰底、无占位/预加载（预载代码被注释 `paginator.js:1178-1221`） |

**不走 WebView 路线的四个理由**：① PRD v2.4 已放弃 Web 平台，foliate-js 是浏览器引擎资产，五平台 WebView（WebView2/WKWebView/Android WebView）一致性、体积、内存全不可控，与 §15.3「诚实降级」相性差；② 玻璃态导航层要叠在正文之上，WebView 合成层与 Flutter 玻璃层的混合是平台相关深坑；③ 本项目解析层（PERF-01/02、isolate、压缩态常驻）已成型且有 226 条 reader 测试护住，换 WebView 全部作废；④ CFI/JS 代码资产脱离 Dart 工具链（analyze/test 不可达）。
**照抄**：**字符偏移为进度真值** + 几何位置二分反推（正是本项目 `chapterPos` 该演进的方向）；开书延迟清单（§2.1）；relocate/采样防抖与「拖动期跳过昂贵计算」。

### 1.3 legado_flutter-2026（Flutter 移植参考）——同构参考 + 正反两面教材

**路线**：纯 Dart 解析（`archive`+`xml` 手工解析，`epub_parser.dart:10-116`）→ `ContentProcessor` 处理流水线 → **`ChapterLayoutProvider` 按行测量分页**（`TextPainter.computeLineMetrics` 拆行、逐行累高切页，`chapter_layout_provider.dart:208-295`）→ `PageView.builder` + `Text` 渲染（`reader_view_paged.dart:22-65`）。翻页动画设置五选项（覆盖/滑动/仿真/滚动/无动画，`app_status.dart:63-75`）——**与负责人点名的模式集合重合**。

**⚠️ 该仓有两套引擎**：接线的主链路是**半成品**；`services/reader/` 下的 Paginator/PaginationCache/ReadingPositionManager/ReaderController **设计正确但零调用**。抄「未接线设计」、**避「活跃链路」**：

## 2. MReader 落地方案（按四保证组织）

### 2.1 保证 1：打开图书性能高、不肉眼卡顿

开书成本 = 结构解析 + 目标章抽取 + **分页排版（新增大头）** + 上屏。对策分四层：

1. **结构缓存（重开零解析）**：`parseEpubStructure` 结果按 `bookId + 文件 mtime/size` 落盘缓存，文件未变则**跳过整个解析**（567Reader `BookExtensions.kt:303-305` 同款判据）。当前 `ReaderPage._open()` 每次都 `source.load()` 重解析（`reader_page.dart:344`），书越重越吃亏——这是本项目相对 567Reader 最大的差距，也是最便宜的补法。
2. **目标页增量分页（先 5 页、后台补完）**：直译 legado_flutter `paginateIncremental` 思路——进章后**立即分出目标页附近的几页上屏**，其余页空闲帧补完（每帧排版预算 ~4-8ms，超时让出）。567Reader「排到目标位才上屏」的口径保留，但 Flutter 下配合增量分页，占位期从「整章排版」缩到「几页排版」。
3. **延迟一切非目标章工作**：PERF-02 压缩态常驻与 `ChapterCache` LRU 30 不动；±1 章**预分页**放空闲帧（三章窗口，567Reader/legado_flutter 同款）；图片继续走 `ImageCacheLRU`。
4. **（可选，拍板）章节正文磁盘缓存**：抽取后的 `ExtractedSection`（paragraphs JSON）按 `bookId+href` 落盘，二次开书免解压免抽取（567Reader `book_cache` 同款）。代价是磁盘占用与一致性管理；若结构缓存 + 增量分页已达标可后置。

### 2.2 保证 2：全书进度、章节进度准确

**真值模型（三家收敛的共同结论）：字符偏移**。567Reader `durChapterPos`（字符索引）、anx CFI（文本节点+字符偏移）、legado_flutter 未接线 `ReadingPositionManager`（charOffset）——三者独立实现都选了字符偏移，而 legado_flutter 活跃链路的「页码」是公认反例（换字号失效）。本项目现 `chapterPos` 是**几何比例**（`clamp(-top/height)`，`anchor.dart:45`），分页后必须改造：

| 层 | 方案 |
|---|---|
| 章内进度 | `chapterPos` 语义改为 **`ExtractedSection.paragraphs` 稳定文本上的字符偏移比例**（`charOffset / totalChars`，继续 clamp 0..1）——保留字段与 JSON 格式（跨设备同步 `SYNC-02` 比较逻辑不变），语义升级为排版无关。落盘文件读旧值时按几何比例**宽容接受**（首帧按比例估算落位，写回时归一为字符口径） |
| 全书进度 | **字数加权**：`(前章字数 + 章内偏移) / totalCharCount()`——原料已在（`book_source.dart:129` `totalCharCount()`，EPUB/TXT 已实现）；图片页/PDF 伪章退化为**页数加权**。修掉 567Reader 章节等权「短章快翻进度飞、长章进度不动」的观感失真，对齐 `TYP-09` 「第 12/87 章 · 43%」的显示口径 |
| 采样 | 翻页/滚动停手后采样**页首字符偏移**（567Reader 同款粒度）+ 页内可见比例细分；拖动/动画中**跳过采样**（anx relocate 防抖同款）；RC1「未收敛不写盘」在分页模型下简化为「动画中不写盘」 |
| 重排恢复 | 字号/行距/边距变更 → 记 charOffset → 重分页 → **二分** `findPageByCharOffset` 落位（legado_flutter `paginator.dart:210-233` 直译）——这同时服务保证 4 |

### 2.3 保证 3：翻页/滚动动画流畅不丢帧

**总原则（567Reader 第一性原理的 Flutter 翻译）：动画期间绝不排版、绝不 rebuild 文本**——动画只操作**已排版页的图层**：

1. **页即图层**：每页一个 `RepaintBoundary` 包裹的静态 widget（行/段 `Text.rich`，复用 `typeset.dart`），排版完成后**不再变化**；翻页动画 = 两页（或三页）图层的 `Transform`/`ClipRect` 位移与裁切（slide 平移、cover 新页盖旧页 + 边缘阴影）——对应 567Reader 的截图回放，但 Flutter 中 widget 树静态 + RepaintBoundary 已天然获得「合成层回放」效果，无需真截图。
2. **相邻页预排**：prev/cur/next（+远端一页）在**空闲帧提前分页并 build**（567Reader `preRenderPage` 4 页窗口的对应物），翻页时目标页已在树中，动画起点零成本。
3. **手势跟手**：拖动期间只改 Transform 值（`setState` 只动动画参数、页子树 `const` 化）；松手按速度阈值 commit/cancel（anx `snap()` 0.3 阈值 / 567Reader `Scroller` 同款语义）。
4. **滚动模式（若保留）**：滚动即页的纵向连续拼接，惯性用 `ClampingScrollPhysics`/`fling`；滚动期间**跳过进度采样**，停手防抖 200ms 再采（anx 同款）。
5. **仿真翻页（若做，建议 P2）**：唯一需要真截图的模式（页面弯曲变形），直译 567Reader 3 张可复用 Bitmap + Matrix/贝塞尔阴影（`SimulationPageDelegate.kt:103-158`），Flutter 侧用 `RenderRepaintBoundary.toImage` 截图 + `CustomPaint` 变形——**实现成本最高，先滑动/覆盖两种跑通再评估**。
6. **护栏**：巨型单 `Text` 继续禁（PERF-03 逐段渲染保留）；玻璃导航层不进正文合成路径（UI-04 红线）。

### 2.4 保证 4：目录跳转迅速、不肉眼卡顿

分页模型把跳转从「滚动 + 语义校正收敛」（现 `reader_page.dart` ≤8 帧校正环）简化为**纯索引定位**：

1. **目录数据即时**：章节表来自结构缓存/解析结果，`TocSheet` 直接可开（现状已满足，NAV-01 不动）。
2. **点击瞬间占位上屏**（567Reader/legado_flutter 同款）：立即切章 + 显示占位页（章标题或 loading 行），**界面零空等**；禁止「先按估算比例显示再跳动校正」——一次性落位，无两级过程。
3. **三章窗口预分页**：prev/cur/next 空闲帧预分页，**相邻跳转秒开**（legado_flutter `reader_logic.dart:136-146` 轮转直译）。
4. **落位 O(log n)**：目标章分页到目标页即 `jumpToPage`（页码由 charOffset 二分）；目标页未排完则增量排版优先排它（与保证 1 的「目标页优先」同一调度器）。
5. **正文链接跳转/搜索跳转同构**：`LinkBackStack`、搜索命中跳转都走「charOffset → 二分页码 → jumpToPage」，段落级定位降级为页级 + 页内滚动微调（可选）。

## 3. 分页引擎设计（核心新增件）

```
ChapterContent(paragraphs, imagePages)
   └→ PagePaginator（主 isolate 增量排版，时间预算）
        输入：paragraphs + 排版参数（字号/行距/边距/视口高宽）
        输出：List<PageLayout>，每页 = 行列表 + [startChar, endChar) + 章内页码
   └→ PaginationCache（LRU ~5 章，key = href|宽|高|字号|行距|字族…配置哈希）
   └→ ReaderPage 视图层：PageView/Stack + 翻页控制器（slide / cover / scroll / none）
```

| 设计点 | 决定 | 依据 |
|---|---|---|
| 测量方式 | **按行测量累高切页**（`TextPainter.computeLineMetrics`）为主，**贪心 `getPositionForOffset` + 断句优化**为辅（长段跨页时找「。！？；>，、>空格>换行」断点） | legado_flutter 两套实现合并：行归属明确（字符偏移好算）+ 断句不切在词中 |
| 排版线程 | **root isolate 增量排版**（每帧时间预算，先目标页后其余）；**不搞** compute/后台 isolate 文本排版 | dart:ui 只在 root isolate；legado_flutter 的 `compute(TextPainter)` 是死代码且存疑 |
| 页 ↔ 字符 | 每页记录 `[startChar, endChar)`；charOffset → 页 = **二分**；页 → 进度 = 页首 charOffset | 三家共同模型；legado_flutter `findPageByCharOffset` 直译 |
| 缓存失效 | 配置哈希（宽/高/字号/行距/字距/字重/字族）变化整体失效；LRU 5 章 | legado_flutter `pagination_cache.dart` 直译 |
| 图片页/PDF | `imagePages` 天然一页一图（`US-12`/`FMT-02` 单/双页同构）；PDF 伪章 = 页序列 | 现有 `ChapterContent` 模型不动 |
| 兜底 | 空页/超长单段/排版异常：至少推进 1 字符 + 异常消息页，绝不死循环 | legado_flutter `paginator.dart:67-69,103-106` + 本项目 RD-05 错误口径 |

**与现有件的衔接**：

| 现有件 | 处置 |
|---|---|
| 解析层（PERF-01/02、`EpubSection.lazy`、isolate） | **原样保留**，与呈现正交 |
| `ChapterCache` LRU 30 / `ChapterAutoLoader` | 保留，窗口职责从「章加载」扩展到「章分页」 |
| `typeset.dart`（NUL 标记、`<b>/<i>`、图片 WidgetSpan、链接） | 保留为**页内容构建器**（行→InlineSpan） |
| `reading_progress.dart` `detectChapterAt`（视口顶探测） | 退役，改「页 → 章 + 章内 charOffset」映射 |
| `anchor.dart` 布局突变语义重锚、≤8 帧校正收敛、占位高估算 | **大幅简化/退役**——分页落位是一次性的，无「校正环」；保留「重排后 charOffset 二分落位」一件事 |
| `reader_page.dart` ListView 连续滚动 | 改分页视图 + 翻页控制器（本方案主体工程量） |

| 模式 | 实现 | 优先级建议 | 参照 |

## 5. 风险与如实登记

1. **增量分页的调度复杂度**：每帧预算、目标页优先、让出机制要防「翻页动画期间被排版任务插队」——动画期冻结排版队列（567Reader 动画期零排版的纪律）。
2. **`chapterPos` 语义迁移**：旧落盘值（几何比例）与新值（字符比例）同名不同义，需版本位或宽容读取；`SYNC-02` 跨设备「取更新」比大小在迁移期可能比错一次（可接受，写回后归一）。
3. **TextPainter 测量与真实 `Text.rich` 渲染的一致性**：行断必须与渲染一致，否则页内文本溢出/留白——用同一套 `TextStyle` 测量与渲染，加 golden/契约测试钉行数。
4. **legado_flutter 活跃链路的半成品性质**：其运行时行为（本地书正文取不到、裸 HTML 显示、字号变更不重排）**未经运行验证**，本文件只采信其「未接线设计」的代码事实，不采信运行结论。
5. **anx 的 `sizePerTimeUnit`/location 语义**是 foliate-js 上游惯例推断，本方案不引入。
6. **工程量自估**：分页引擎 + 翻页控制器 + reader_page 改造 + 进度语义迁移 ≈ M1-T04 同量级的主体工程（含测试迁移），建议独立里程碑排期（如 M5 或 M3.5 后插入），不与统计/AI 混批。

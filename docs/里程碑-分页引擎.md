## 0. 全里程碑共享定义：字符偏移空间

`chapterPos` 真值（§6 ②）的偏移空间**一处定义、处处引用**：

| 项 | 定义 |
|---|---|
| 空间 | `ExtractedSection.paragraphs` 各段**原文**（含 `\x00` 标记与 `<b>/<i>` 标签）按顺序**无分隔符**拼接 |
| 偏移 | `joinedOffset = Σ paragraphs[0..i).length + offsetInParagraph[i]` |
| 总长 | `totalChars = Σ paragraph.length`（UTF-16 code unit；与 `BookSource.totalCharCount` 的「`paragraph.length` 累加」口径一致，全书进度 `(前章字数 + 章内偏移) / totalCharCount()` 天然连续） |
| 进度 | `chapterPos = charOffset / totalChars`，继续 clamp 0..1；**字段与 JSON 格式不变**（`SYNC-02` 比较逻辑不动）；旧落盘几何比例值**宽容读取**（首帧按比例估算落位、写回归一） |

可见文本投影（排版 offset 空间）：剥 `\x00` 标记（IMG → 1 个 `U+FFFC` 槽位）与 `<b>/<i>` 标签；行测量的偏移经投影表映射回上述原文空间。投影语义与 `typeset.dart` 的 span 构建**必须一致**（契约测试钉死）。

## 2. T01 边界登记（如实）

1. **图片占位**：测量用 `WidgetSpan` + `setPlaceholderDimensions(48×48, middle)`（= `_InlineImage` 加载 / 错误态尺寸；`TextPainter` 未设维度会**忽略**占位，已核 SDK `text_painter.dart:1055-1063`）。真图尺寸进测量在 **T05**（接 `ImageCacheLRU` 后按实测尺寸重分页 + charOffset 重锚）。
2. **章标题**不在 T01 输入（只吃 `List<String> paragraphs`）；是否作为首段进分页在 T05 定。
3. **增量排版 / 时间预算**在 T02；T01 只做全量测量。
4. **断句优化（合并版）**：切页点 = 行边界（词完整性由行断保证）；切在段中间时**页尾回拉**到更好的行边界——类别优先（段末/句读 `。！？；…` > 逗顿 `，、` > 空格），同类取最靠后；回拉窗口 ≤50 字符（legado `paginator.dart:114-142` 直译）且回拉后页内 ≥1 行；无合适断点维持原切点。
5. **行字符区间**：`LineMetrics` 无 startIndex/endIndex（SDK `text.dart:2865-2889` 已核）⇒ 行首取 `getPositionForOffset(行垂直中点 x=0)`，行尾 = 下一行行首（末行 = 段末），legado `chapter_layout_provider.dart:263-287` 同款技巧的稳健版。
